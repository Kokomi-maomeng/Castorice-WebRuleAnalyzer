# Castorice-WebRuleAnalyzer v1.5

Windows x64 原生窗口便携版。下载 ZIP 后，解压到可写目录，双击 `Castorice-WebRuleAnalyzer.exe`。需要系统已有 Edge WebView2 Runtime 与 Chrome/Edge，不需要开发工具。

输入网站，选择模式并分析。左侧是实际观察域名，右侧选项卡查看请求、日志和规则命中。小窗口会切换面板或收起部分选项，高级参数在弹窗中。

规则库 → 规则库设置：可开启按来源自动更新，或手动下载/检查新版本。首次下载完成后搜索分类名或规则域名；点击分类直接查看原始 YAML/文本，可全选、复制、编辑、恢复或下载。编辑不会修改匹配缓存。未转换的 IP/ASN 等条目仍保留在原文中。

匹配区分目标主机、第三方依赖与关键词。核对具体规则后再决定是否合并；`gemini.com` 与 `gemini.google.com` 不属于同一应用。默认仅导出本次观察结果。

预览选择“抓取 + 开源规则库”后，如果提示未下载，可直接点击“下载规则库”。两套来源按顺序下载，完成后输入分类名称匹配并选择；空白输入不展开候选。分类框标有必选星号，没有选择分类时仍显示抓取预览，选择后才能下载合并结果。搜索内容不会因规则库轮询而清空。

条目默认每页 30 条，支持搜索域名或来源分类，筛选本次抓取、被覆盖及合并模式中的规则库补充；双方匹配也属于本次抓取。表头复选框只操作当前页，翻页搜索保留选择。“恢复全选”恢复全部条目。文件内容按行翻页，复制与下载仍包含完整文件。手机或短窗口可点击标题右侧“导出设置”展开、收起选项；选择分类不会自动收起设置。

抓取失败、未完成或规则范围提示收在预览标题旁的提示图标中；DOMAIN-SUFFIX 的说明在该选项旁。鼠标悬停或点击图标可查看，按 Escape 或点击外部可收起。默认使用精确 DOMAIN；后缀匹配会扩大到所观察域名的全部子域名。重新计算时列表保持原位，计算完成前无法下载过期内容。

“清空工作区”恢复最初页面，输入框清空后回车也可清空；不会删除历史、缓存与软件设置。刷新后保持空白，可随时从历史重新打开。采集中请先停止再清空。交互动效跟随系统“减少动态效果”偏好。

设置、历史、规则缓存和 WebView2 缓存存于软件旁 `data/`，导出文件存于 `exports/`。正常关闭主窗口会取消任务并清理本次创建的浏览器和临时 Profile。移动软件时携带整个文件夹。替换旧版前先退出并备份数据目录。

自动更新只在软件运行期间工作，不安装系统后台任务；更新失败使用已有缓存。请勿在 ZIP 内运行、把应用放在不可写的目录、或将自己的 data/exports 目录上传。

Linux 使用附带的 `start.sh` 或 `./castorice --server` 启动本地网页界面。Docker 参阅 README 与 compose.yaml。容器没有图形会话时仅提供无头采集。

更多边界和实际验证范围见 README 与 docs/TEST-REPORT.md。本项目不是系统抓包器，有限扫描不证明应用所有功能完整覆盖。

查看历史时，如另有任务正在采集，可直接停止或返回活动任务。规范的 www / HTTPS 跳转会继续探索；跨站点跳转会明确提示仅观察当前页。

规则源更新不会清空正在编辑的临时草稿。同一分类的新原文可点击“采用新原文”；临时编辑始终只用于复制/下载，不改变匹配。合并导出在更新后重新计算，复制和下载前也会核对所选分类版本。

导出的文件是规则片段或规则集，需接入已有代理客户端。Clash 策略组要已存在；Rule Provider 和 sing-box 要在客户端中引用，见 [导出接入说明](EXPORT-INTEGRATION.md)。

## 网络诊断与历史管理

遇到地址或连接问题时，点击主界面“网络诊断”。默认自动模式只对已知 Fake-IP 做安全回退；系统返回回环、私网或混合受限地址时会明确阻止并解释。选择“独立安全 DNS”会改用所选 HTTPS DNS 的答案，所有实际连接仍须通过公网校验。Cloudflare 与 Google 可选；可配置无认证的本机 HTTP/SOCKS5 代理，例如填写自己客户端的回环 IP 和监听端口。留空使用系统网络，TUN 仍可接管它。诊断只证明解析及 TCP 连接结果，登录、证书和业务内容需要实际扫描核对。

网络诊断中的“用于本次扫描”和高级参数只改变下一次扫描；软件设置中保存的选项才是默认值。程序不会修改操作系统 DNS 或代理客户端配置。

新地址未能启动时，下方旧结果会明确标注来源。请求失败、HTTP 错误、未完成和页面覆盖统计分别显示；失败域名仍可按需导出用于排障。200 响应也可能是登录或风控页面，请核对最终地址和标题。

扫描历史支持搜索、分页、单条删除、多选删除和“清空已结束历史”。确认后删除相应任务、域名、请求和日志；所有页的已结束记录均在清空范围内。运行中的任务、规则缓存、设置及已经导出的文件保留。清空工作区仍只重置当前页面。
