# Castorice-WebRuleAnalyzer v1.7

Windows x64 原生窗口便携版。先核对 ZIP 的 SHA-256，再解压到可写目录，双击 `Castorice-WebRuleAnalyzer.exe`。本地候选版未签名。Windows 桌面需要 Edge WebView2 Runtime 和已安装的 Chrome、Edge 或 Chromium。 [微软 WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)

输入网站，选择模式并分析。粘贴完整网址时，输入框会保留域名，并在下方短暂提示已清除的部分；采集按网址的协议和端口从站点首页开始。地址有问题时，可悬停、点击或用键盘聚焦输入框右侧的提示按钮。左侧是实际观察域名，右侧选项卡查看请求、日志和规则命中。小窗口会切换面板或收起部分选项，高级参数在弹窗中。

规则库 → 规则库设置：可开启按来源自动更新，或手动下载/检查新版本。首次下载完成后搜索分类名或规则域名；点击分类直接查看原始 YAML/文本，可全选、复制、编辑、恢复或下载。编辑不会修改匹配缓存。未转换的 IP/ASN 等条目仍保留在原文中。

匹配区分目标主机、第三方依赖与关键词。核对具体规则后再决定是否合并。默认仅导出本次观察结果。

预览选择“抓取 + 开源规则库”后，如果提示未下载，可直接点击“下载规则库”。两套来源按顺序下载，完成后输入分类名称匹配并选择；空白输入不展开候选。分类框标有必选星号，没有选择分类时仍显示抓取预览，选择后才能下载合并结果。搜索内容不会因规则库轮询而清空。

条目默认每页 30 条，支持搜索域名或来源分类，筛选本次抓取、被覆盖及合并模式中的规则库补充；双方匹配也属于本次抓取。表头复选框只操作当前页，翻页搜索保留选择。“恢复全选”恢复全部条目。文件内容按行翻页，复制与下载仍包含完整文件。手机或短窗口可点击标题右侧“导出设置”展开、收起选项；选择分类不会自动收起设置。

抓取失败、未完成或规则范围提示收在预览标题旁的提示图标中；DOMAIN-SUFFIX 的说明在该选项旁。鼠标悬停或点击图标可查看，按 Escape 或点击外部可收起。默认使用精确 DOMAIN；后缀匹配会扩大到所观察域名的全部子域名。重新计算时列表保持原位，计算完成前无法下载过期内容。

启动和刷新都打开空白工作区。采集按钮右侧的“清空工作区”会重置当前页面，清空网址后回车也可重置。历史、缓存与软件设置保留。采集中请先停止再清空。交互动效跟随系统“减少动态效果”偏好。

设置、历史、规则缓存和 WebView2 缓存存于软件旁 `data/`，导出文件存于 `exports/`。正常关闭主窗口会取消任务并清理本次创建的浏览器和临时 Profile。换电脑时先正常退出旧版，备份这两个目录，再复制到新解压的软件目录。便携目录一次由一个实例使用。自定义的浏览器路径只保留已经检测到的选项。

自动更新只在软件运行期间工作，不安装系统后台任务；更新失败使用已有缓存。请勿在 ZIP 内运行、把应用放在不可写的目录、或将自己的 data/exports 目录上传。

Linux 图形会话中使用附带的 `start.sh` 或 `./castorice --desktop` 打开桌面窗口，依赖见 README。使用 `./castorice --server` 可启动网页服务。Docker 参阅 README 与 compose.yaml。容器没有图形会话时仅提供无头采集。

## 扫描模式与浏览器

模式菜单左侧的问号可查看说明。快速扫描访问一个页面，使用总时长、导航超时、页面观察和静默等待。自动探索还使用探索深度、最多页面和页面间隔。辅助交互由你在受控浏览器中操作，使用总时长、导航超时和页面数上限。DNS 和代理可用于三种模式。

“默认显示受控浏览器”开启后，快速扫描和自动探索会显示独立的采集窗口，方便观察加载过程。关闭时这两种模式在无头浏览器中采集。辅助交互始终显示窗口。每次启动使用独立的临时浏览器资料。

采集范围限于受控标签页和可观察的网络事件，详见 [测试范围](TEST-REPORT.md)。

查看历史时，如另有任务正在采集，可直接停止或返回活动任务。规范的 www / HTTPS 跳转会继续探索；跨站点跳转会明确提示仅观察当前页。

规则源更新不会清空正在编辑的临时草稿。同一分类的新原文可点击“采用新原文”；临时编辑始终只用于复制/下载，不改变匹配。合并导出在更新后重新计算，复制和下载前也会核对所选分类版本。

导出的文件是规则片段或规则集，需接入已有代理客户端。Clash/Mihomo 的策略组名称可从客户端配置的 `proxy-groups` 查到，默认值 `PROXY` 需按实际配置核对。合并规则复制先校验版本，然后点击复制。剪贴板不可用时，在文件内容页选择完整文本或下载文件。 [导出接入说明](EXPORT-INTEGRATION.md)

## 网络诊断与历史管理

遇到地址或连接问题时，从“高级配置”打开“网络诊断”。诊断默认使用系统解析，勾选对照会向界面标明的 Google 或 Cloudflare 查询公网目标名。扫描的自动模式可对已知 Fake-IP 使用 HTTPS DNS 回退。规则库下载通过服务进程的网络和代理环境访问 GitHub。诊断显示解析及 TCP 连接证据，证书和业务内容以实际扫描为准。

网络诊断中的“用于本次扫描”和高级参数只改变下一次扫描；软件设置中保存的选项才是默认值。程序不会修改操作系统 DNS 或代理客户端配置。

新地址未能启动时，输入框提示卡片也会说明下方保留了上次结果。请求失败、HTTP 错误、未完成和页面覆盖统计分别显示；失败域名仍可按需导出用于排障。200 响应也可能是登录或风控页面，请核对最终地址和标题。

扫描历史支持搜索、单条删除、多选删除和“清空已结束历史”。条数和分页位于固定底栏，滚动记录时保持可见。新任务的历史目标显示域名，打开旧的脱敏任务后可填写域名重新采集。历史匹配标注当时使用的规则版本，缓存已更新时会提示并提供历史上游入口。确认删除的任务会连同域名、请求和日志一起删除。
