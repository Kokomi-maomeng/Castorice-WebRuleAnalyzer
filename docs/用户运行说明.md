# Castorice-WebRuleAnalyzer v1.0

Web分流规则分析器。普通用户只需要本机已安装 Chrome、Edge 或 Chromium，不需要 Go、Node.js、Python 或 Rust。

1. 解压整个运行包，双击 `Castorice-WebRuleAnalyzer.exe`。
2. 程序启动本地服务并自动打开浏览器界面。默认地址为 `http://127.0.0.1:19110`。
3. 输入网址，选择快速扫描、自动探索或辅助交互，再开始分析。
4. 等待结束，或点击停止。辅助交互在独立浏览器的当前标签页内操作，完成后点击停止。
5. 左侧勾选观察域名，点击“预览与导出规则”。默认只导出精确 `DOMAIN` 规则。
6. 如需合并开源规则，先在“规则库”初始化来源，再重新匹配。选择“抓取 + 开源规则库”，核对分类和逐条来源后导出。
7. 控制台窗口按 Ctrl+C 可退出服务并释放扫描浏览器。关闭 GUI 标签页不等同于关闭服务。

Clash / Mihomo YAML 需填写已有策略组名称。Rule Provider 文件需要在客户端配置中声明 `behavior: classical` 并由 RULE-SET 指定策略。sing-box JSON 使用 Source Rule Set v3，目标 sing-box 1.11+；不是完整客户端配置。

设置及扫描历史默认保存在 `%APPDATA%\Castorice-WebRuleAnalyzer\castorice.db`。首次运行不下载规则库；离线时可以使用已有规则缓存，扫描网站仍需要网络。浏览器 Profile 会在扫描结束后删除；异常退出残留可在设置中清理。

端口被占用时，在命令行运行 `Castorice-WebRuleAnalyzer.exe --listen 127.0.0.1:19112`。如果自动打开失败，可手动使用控制台打印的地址。浏览器不存在时，在设置中选择检测到的浏览器或填写浏览器路径。

HTTP/3/QUIC 默认关闭以保持网络目标保护；HTTP/HTTPS、XHR/Fetch、WebSocket 通过浏览器 CDP 观察。当前标签页以外的新标签页、独立 Worker，以及需要未执行交互才产生的请求可能没有覆盖。未自动登录、未绕过网站安全验证。

本软件没有系统透明抓包、PCAP 解码或 HTTPS 中间人解密。查询参数值已脱敏；不要把有限扫描当成整个应用完整覆盖。外部规则和关键词匹配可能扩大范围，请核对后使用，并遵守上游许可证。合并导出时可以下载 `.sources.txt` 来源说明。
