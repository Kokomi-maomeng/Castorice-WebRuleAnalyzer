# Castorice-WebRuleAnalyzer v2.2 使用说明

软件标题栏显示正在运行的版本，发行版的实测范围见 [测试报告](TEST-REPORT.md)。

Windows x64 原生窗口便携版。先核对 ZIP 的 SHA-256，再解压到可写目录，双击 `Castorice-WebRuleAnalyzer.exe`。Windows 便携 EXE 未签名，桌面需要 Edge WebView2 Runtime 和已安装的 Chrome、Edge 或 Chromium。 [微软 WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)

在网址左侧选择模式。较窄的窗口中，模式位于输入框上方。粘贴完整网址后，输入框保留域名，采集按原网址的协议和端口从站点首页开始。地址有问题时，可以悬停或点击输入框右侧的提示按钮。左侧显示实际观察到的域名，右侧查看请求、日志和规则命中。小窗口可切换面板，参数在右上角的软件设置中调整。

「开源规则库」的原文右侧可按来源开启自动更新、手动下载或检查新版本。「复制」右边的按钮可收起或展开设置。空间较小时设置自动收起，手动展开可用完整宽度管理。清理规则库需要确认，自动更新开关会保留。下载后可搜索分类名或规则域名。打开分类可查看带行号的原始 YAML 或纯文本，也可全选、复制、编辑或恢复原文。编辑使用临时草稿，匹配使用缓存快照。未转换的 IP/ASN 等条目仍可在原文中查看。

匹配区分目标主机、第三方依赖与关键词。核对具体规则后再决定是否合并。默认仅导出本次观察结果。

点击域名行可打开该主机的网络请求。Ctrl 点击切换选择，Shift 点击可选择范围。列表顶部可全选、清空选择、切换排序方向并查看选中数与域名总数。放大镜展开搜索。焦点在域名或预览条目列表时，Ctrl+A（macOS 上为 ⌘A）选中当前筛选的全部可勾选条目，包括预览后续页。文字输入框和编辑区中的快捷键选中当前文字。

导出范围和输出格式可在面板里直接单选。选择“抓取结果+开源规则库”后，可以搜索本地已缓存的分类。没有可用分类时，分类框旁会出现“下载规则库”，下载期间会显示进度。清空搜索可收起候选，刷新分类列表会保留搜索内容。选定分类后即可下载合并结果。

文件名称在导出窗口底部，默认值为 `castorice-rules`。软件会按输出格式添加扩展名。清空名称会禁用“保存到软件目录”。

条目默认每页 30 条，支持搜索域名或来源分类，筛选本次抓取、被覆盖及合并模式中的规则库补充；双方匹配也属于本次抓取。表头复选框只操作当前页，翻页搜索保留选择。“恢复全选”恢复全部条目。文件内容默认按行翻页，选择“完整显示”可连续查看全部内容和行号。条目可以整行勾选，Shift 点击选择范围。导出设置默认展开，收起时同时隐藏抓取范围和输出格式。

抓取失败、未完成或规则范围提示收在预览标题旁的提示图标中；DOMAIN-SUFFIX 的说明在该选项旁。鼠标悬停或点击图标可查看，按 Escape 或点击外部可收起。默认使用精确 DOMAIN；后缀匹配会扩大到所观察域名的全部子域名。重新计算时列表保持原位，计算完成前无法下载过期内容。

启动和刷新都打开空白工作区。采集按钮旁的「重置工作区」会重置当前页面，清空网址后回车也可重置。历史、规则库与软件设置保留。采集中可先停止再重置。交互动效跟随系统“减少动态效果”偏好。主题在软件设置中选择。标题栏的减号和加号调节缩放，点击百分比可恢复 100%。

设置、历史、规则缓存和 WebView2 缓存存于软件旁 `data/`，导出文件存于 `exports/`。正常关闭主窗口会取消任务并清理本次创建的浏览器和临时 Profile。换电脑时先正常退出旧版，备份这两个目录，再复制到新解压的软件目录。便携目录一次由一个实例使用。自定义的浏览器路径只保留已经检测到的选项。

自动更新只在软件运行期间工作，不安装系统后台任务；更新失败使用已有缓存。请勿在 ZIP 内运行、把应用放在不可写的目录、或将自己的 data/exports 目录上传。

Linux 图形会话中使用附带的 `start.sh` 或 `./castorice --desktop` 打开桌面窗口，使用 `./castorice --server` 可启动网页服务。默认 Docker 容器无图形会话，使用快速和深度模式时通过无头浏览器采集，自行交互置灰。macOS 从终端运行 `./start.sh`，在默认浏览器打开界面。各端共用工作区、软件设置、规则库和导出交互。

## 扫描模式与浏览器

在主界面直接选择“快速”“深度”或“自行交互”，鼠标悬停或点击可查看说明。快速模式访问一个页面，使用总时长、导航超时、页面观察和静默等待。深度模式还使用探索深度、最多页面和页面间隔。自行交互由你在受控浏览器中操作，使用总时长、导航超时和页面数上限。DNS 和代理可用于三种模式。

右上角「软件设置」顶部是浏览器与会话。下方的扫描参数按模式查看和保存。采集时，分析页签区显示本次采用的参数。采集结束后，该处显示下次生效的参数，将鼠标放在摘要上可查看本次记录。

“显示受控浏览器”开启后，快速和深度模式会显示独立的采集窗口，方便观察加载过程。关闭时这两种模式在无头浏览器中采集。自行交互始终显示窗口。每次启动使用独立的临时浏览器资料。

采集范围限于受控标签页和可观察的网络事件。

查看历史时，如另有任务正在采集，可直接停止或返回活动任务。规范的 www / HTTPS 跳转会继续探索；跨站点跳转会明确提示仅观察当前页。

规则源更新不会清空正在编辑的临时草稿。同一分类的新原文可点击“采用新原文”；临时编辑始终只用于复制/下载，不改变匹配。合并导出在更新后重新计算，复制和下载前也会核对所选分类版本。

导出的文件是规则片段或规则集，需接入已有代理客户端。Clash/Mihomo 的策略组名称可从客户端配置的 `proxy-groups` 查到，默认值 `PROXY` 需按实际配置核对。点击“文件内容”旁的铅笔可编辑预览，再点一次可回到预览。复制和保存使用编辑后的内容。剪贴板不可用时，可在文件内容页切换到“完整显示”，再手动选择所需文本或下载文件。 [导出接入说明](EXPORT-INTEGRATION.md)

## 网络诊断与历史管理

遇到地址或连接问题时，点击右上角“软件设置”左边的“网络诊断”。诊断会采用软件设置中的 DNS 和代理作为初始选项，勾选对照会向界面标明的 Google 或 Cloudflare 查询公网目标名。扫描的自动模式可对已知 Fake-IP 使用 HTTPS DNS 回退。规则库下载通过服务进程的网络和代理环境访问 GitHub。诊断显示解析及 TCP 连接证据，证书和业务内容以实际扫描为准。

网络诊断中的临时选项可用于测试。点击“用于下次扫描”可将选择的 DNS 和代理用于下一轮采集。长期使用的采集参数在“软件设置”中保存。

勾选「探测 QUIC / HTTP/3」可查看网站的 Alt-Svc 声明、实际协商协议和状态码。使用本机代理时可明确选择独立通过系统网络探测 UDP。日常浏览器采集继续使用受控的连接路径。

新地址未能启动时，输入框提示卡片也会说明下方保留了上次结果。请求失败、HTTP 错误、未完成和页面覆盖统计分别显示；失败域名仍可按需导出用于排障。200 响应也可能是登录或风控页面，请核对最终地址和标题。

扫描历史支持直接打开、搜索、单条删除、多选删除和“清空已结束历史”。按 Ctrl 可以改变单条选择，按 Shift 可以选择范围，焦点在记录列表内时全选快捷键选择当前页的已结束记录。条数和分页位于固定底栏，滚动记录时保持可见。新任务的历史目标显示域名，打开旧的脱敏任务后可填写域名重新采集。历史匹配标注当时使用的规则版本，缓存已更新时会提示并提供历史上游入口。确认删除的任务会连同域名、请求和日志一起删除。
