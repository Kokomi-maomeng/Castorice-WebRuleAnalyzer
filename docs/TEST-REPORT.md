# v2.2 测试报告

发行包共用前端和 Go 服务。Windows 桌面使用 WebView2，Linux 桌面使用 GTK/WebKitGTK，Docker 和 macOS 使用浏览器界面。

| 平台 | 验收范围 |
| --- | --- |
| Windows x64 | 便携程序在原生 WebView2 中完成公网采集，检查模式提示、缩放后的规则库侧栏、域名与导出全选、编辑区原生全选。三种文件格式写入成功。验证正常关闭、采集中关闭、强退和恢复，核对进程、监听和临时采集资料。 |
| Chrome、Edge、Firefox、WebKit | 用隔离站检查实际采集、请求详情、日志、规则命中、桌面与窄窗口布局、分页历史和三种下载。检查输入框与列表的全选范围、触屏事件、自动收起及草稿保留。 |
| Android 13 Chrome 真机 | 使用 Windows 候选包提供网页服务。竖屏 384×771 和横屏 827×303 为浏览器内容区 CSS 像素。实测触控模式说明、紧凑规则设置、采集、扫描状态、规则预览及下载按钮可达性。 |
| Debian 13 x64 | 在 VMware 中解包运行无头服务和原生 GTK/WebKitGTK。两种入口均完成公网采集及三格式导出，原生窗口另验证缩放、设置提示、域名与历史操作、正常关闭和采集中取消。 |
| Docker x64 | 用发行包在同一 VMware 中启动独立 Compose 项目。通过认证、非 root Chromium 和渲染进程沙箱检查，实测快速、深度、三格式导出及单个在线规则源合并。网页端验证自行交互置灰、模式提示、全选和响应式布局。 |
| macOS Intel 与 Apple 芯片 | 分别交叉编译，核对 Mach-O 架构、启动脚本、可执行权限和校验值。本轮未运行 macOS 包。 |

## 显示和操作回归

- 从 1920×1080 桌面、1280×720 笔记本到 320×568 竖屏，验证页面可达、弹窗边界、表格和表单滚动。覆盖 667×375 横屏、320×256 短窗，以及应用 50%、100%、125%、150%、200% 缩放。检查深浅主题、减少动效和触控入口。
- 下拉菜单在缩放后对齐控件。模式在网址前面，悬停或点击显示说明。手机在启动采集期间切换至分析页，采集响应到达后继续显示分析。
- 规则库设置在宽窗位于原文右侧，手动收起能扩大原文。窗口缩小时自动收起并处理焦点，窄窗手动展开后仍能回到编辑草稿。用受控夹具验证清理的确认与取消，用实时规则源核对下载和合并。
- Ctrl+A 或 ⌘A 在文字框保留原生选择，在域名与导出列表选择当前筛选的全部条目，在历史列表选择当前页的已结束记录。工作区空白处不会全选页面文字。
- 软件设置的浏览器与会话位于扫描参数前。检查重置工作区、样式与动画、狭窄窗口下的标签切换，以及导出预览中的条目、文件编辑和保存。

## 代码与发行检查

前端 45 项单元测试、TypeScript、版本同步及格式检查通过。Go 全包测试、vet、真实 Chromium、上游规则源和 DNS 检查通过。npm 依赖检查及 Go 源码与候选二进制的漏洞检查未报告漏洞。

发行包内的 `BUILD-INFO.json` 记录源码提交、源码树、目标架构和程序 SHA-256。五套包分别核验压缩包和执行文件校验值。源码、Git 历史及附件进行敏感信息检查。包只包含程序、公开文档、许可证、部署配置及校验元数据。
