## 实际验证范围

- Windows 11 x64：最终 Go 全包测试、vet、20 项前端测试、严格类型/生产构建；显式启用真实浏览器、上游规则与 DNS 检查。
- Windows 便携 EXE：中文/空格路径、实际公网请求、三格式保存、正常关闭、采集中关闭、强制退出与恢复；所属子进程和监听清理通过。
- Chrome / Edge：明暗主题、320/360/390px 窄屏、横屏、桌面尺寸；活动任务与历史控制实际操作。
- 实际两源：blackmatrix7 679 分类、v2fly 1542 分类；Facebook 547 条预览；最大真实分类 8,723 规则、合并预览 8,732 条，未截断完整复制下载。
- 原有 UI 验收覆盖八种尺寸、文字放大、分页、选择保留、设置折叠、按压、减少动效。5,000 条密集数据另标明为构造夹具。
- Debian 13：持久部署的 systemd 服务以独立非 root 用户运行，仅监听回环；实际公网采集、三格式导出、完整规则下载及重启后缓存保留通过。另在 Xvfb 图形会话验证可见辅助模式启动/停止，不能代替实体显示器、Wayland 或所有桌面环境。
- Docker：Debian 中独立 daemon/containerd 与私有挂载命名空间，不使用 Windows Docker，不改原有容器；非 root Chromium 保留自身沙箱，实际采集、三格式导出与持久卷检查。该本地隔离环境使用 host 网络，默认 Compose 端口映射由 GitHub CI 验证。
- 发布前检查源码、全部可达 Git 历史、提交身份、ZIP 和 tar.gz；只发布公开项目文件，不包含本地部署记录、运行库、扫描数据、日志、浏览器 Profile 或凭据。最终附件校验值置于 Release 的 SHA256SUMS.txt，避免包内自引用。

## 保留的边界

17 项修复不等于证明任意环境绝无漏洞或 bug。Windows 10、全新缺失 Runtime 的安装、macOS、Safari、Firefox 和真实代理客户端的端到端接入未在本轮全部实测；对应说明继续保留。

原审计的 R01 是条件性容器加固项：Compose 仍允许 seccomp/AppArmor 例外以支持 Chromium 用户命名空间；本轮不宣称已消除该风险。需最小权限容器部署时继续评估专属配置，不能用 `--no-sandbox` 绕过。服务器磁盘空间原本紧张，项目实际完整缓存运行已验证，但后续增长仍需容量维护。

网络短时失败会被安全策略拒绝或提示重试；本轮有一次 HTTPS DNS 校验连接失败和一次 npm audit 端点失败，重新执行成功，未降低私网、回环或 DNS 安全校验来通过测试。验收脚本的异步响应关闭竞态亦已修正，避免覆盖真正的断言结果。
