# v1.5 修复与发布验收报告

日期：2026-11-04。根 VERSION 为 1.5.0，应用与发行标签显示 v1.5。本版集中修复预览与导出规则面板。

## 逐项处理

| 要求 | 处理结果 |
| --- | --- |
| 删除冗余文字 | 删除弹窗中的结果来源、模式与格式摘要、策略组辅助文字、本地分类数量与 80 项常驻说明，以及格式接入长提示。 |
| 抓取失败或未完成提示 | 移至标题文字右侧图标，悬停、点击或键盘聚焦可查看浮窗；其他分类范围警告也在该处查看。 |
| 后缀匹配提示 | 两段说明整合至 DOMAIN-SUFFIX 选项旁图标，不占据整行。后端导出的风险语义保留。 |
| 分类候选 | 空白时不展开选项，输入后按名称、来源匹配，并优先精确及前缀命中。 |
| 输入消失与无法选择 | 控制搜索文本并稳定已选值；忽略组件因值对象更新发起的输入重置；轮询复用未改变的数据；按需下载与迟到响应不会覆盖新的选择。 |
| 高缩放列表过小 | 压缩常驻说明、工具栏及来源行；列表保留独立滚动，分页和下载操作可见。 |
| 显示条目筛选 | 保留全部条目，增加本次抓取、被覆盖、规则库补充；仅抓取模式隐藏规则库补充，切换范围重置筛选。双方匹配计入本次抓取。 |
| 选择分类时跳动 | 不再自动收起设置；固定分类输入高度，多选标签在受限宽度内水平滚动；重算期间保留旧列表并禁用过期范围选择和导出。 |
| 控件尺寸与间距 | 统一输入框最小高度、复选框、提示图标和工具栏对齐；修复表头勾选列被相邻粘性表头遮挡的问题。 |

## 代码与应用验证

- 前端 28 项组件与服务测试，包含分类跨轮询保留、按需下载期间继续输入、清空改选后忽略旧下载、旧预览禁用、来源筛选、浮窗和已有分页/完整下载/版本校验回归。
- TypeScript / Vite 构建、格式与版本同步检查、Go 全包测试（启用真实浏览器）、go vet、npm audit，以及源码和 Windows / Linux 成品 govulncheck。
- 真实缓存分类合并预览、跨页保留勾选、三种格式完整复制与下载、8,732 条大分类及明确标注的 5,000 条布局夹具；九种窗口尺寸、字体放大、正常与减少动态效果。
- 2560×1600 / 200% 的浏览器等效检查使用 DPR=2，内容区为 1280×800 及扣除窗口占用后的 1280×720。真实 Facebook 分类分别完整可见 7 条和 5 条，列表高度约 324 与 244 CSS 像素；分类选择逐帧记录的最大列表位移为 0 像素，四分类时输入仍可用。
- 提示支持悬停、点击、Escape 与外部点击关闭；显示条目筛选及仅抓取模式选项隐藏通过浏览器检查。失败/未完成提示的具体文案另有组件回归。
- Windows 原生窗口目视复核、发布 EXE 测试副本的实际采集与三格式保存、正常关闭、活动关闭、强制退出和恢复后再次扫描导出。
- Debian 非 root 候选服务与正式升级后的真实采集、三格式导出和同版本界面检查；升级保留历史、设置、规则缓存与自动更新偏好，无关容器未重启。

## 发布检查与边界

上传前检查源码、待推送 Git 历史、提交身份、发行附件及本地已知敏感值；凭据、部署细节、数据库、日志、浏览器 Profile 和用户个人路径均排除在发布输入之外。附件为干净 Windows ZIP、Linux amd64 tar.gz 和 SHA256 校验文件，不含运行数据或规则库快照。

CI 状态以关联 [Actions](https://github.com/Kokomi-maomeng/Castorice-WebRuleAnalyzer/actions) 为准；发行附件从 GitHub 匿名下载后重新核对哈希。Windows 10、缺少 WebView2 的新环境、macOS、Safari、Firefox及所有物理设备与客户端组合未在本轮全部实测。已通过的检查不构成所有场景无缺陷或网站业务完整可用的证明。
